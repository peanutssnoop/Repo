Python PEP8

Una guía que indica las convenciones estilísticas a seguir para escribir código Python.

Antes de usar PEP8

Se debe realizar la instalación $ pip install autopep8

Después de usar PEP8

Se usó el comando $ py -m autopep8 sintaxis.py -v -i

Se nos recomienda usar espacio con operadores de asignación.py
